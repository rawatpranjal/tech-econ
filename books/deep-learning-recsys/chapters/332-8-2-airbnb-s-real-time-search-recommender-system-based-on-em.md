## 8.2 Airbnb's Real-Time Search Recommender System Based on Embedding

In 2018, Airbnb published a paper titled 'Real-time Personalization using Embeddings for Search Ranking at Airbnb' [3] at KDD, which was awarded the best paper at the conference. The first author of the paper, Mihajlo, Airbnb's senior machine learning scientist, has also shared Airbnb's search recommender system at multiple technical conferences.

As one of the 'core operations' of deep learning, embedding technology can not only convert a large number of sparse features into dense features as the inputs of deep learning networks, but also encode the semantic representations of items through embedding, and directly search for similar items through similarity calculation. Airbnb fully exploited these two advantages of embedding and built its real-time search recommender system based on it.
